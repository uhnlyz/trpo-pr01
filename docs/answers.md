# Короткие ответы к защите

**1. Какие входные данные используются?**

В папке `dataset` находятся `content.csv`, `navigation.json` и две картинки в `assets`. В CSV записаны шесть направлений, их категории, описания и числа. В JSON записаны названия пунктов навигации и цели ссылок.

**2. Где данные попадают на страницу?**

В этой работе я перенёс значения из CSV в HTML вручную. Карточки находятся в разделе `tracks`, а строки таблицы — внутри `tbody`. Отдельного JavaScript-кода для обработки CSV нет.

**3. Какое ошибочное состояние проверялось?**

Проверяю пустые обязательные поля, неправильный email, слишком короткий комментарий и номер семестра меньше 1 или больше 8. Ограничения заданы HTML-атрибутами `required`, `type`, `min`, `max` и `minlength`.

**4. Что можно улучшить, если проект станет больше?**

Можно автоматически создавать карточки из файла с данными и добавить сервер, который будет сохранять отправленные формы. В этой работе это не требуется.

**5. Как проверить проект после скачивания?**

Открыть `index.html` в браузере, пройти по ссылкам, проверить форму и уменьшить ширину окна. В VS Code можно посмотреть HTML и CSS.

**6. Чем HTML отличается от CSS?**

HTML задаёт структуру и содержание страницы. CSS задаёт внешний вид: цвета, размеры, отступы и расположение элементов.

**7. Используется ли JavaScript или Bootstrap?**

Нет. В этой практической работе используются только HTML и CSS, без JavaScript и Bootstrap.
