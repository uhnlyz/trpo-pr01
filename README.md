# Практическая работа № 1 — HTML и CSS

## Что это за проект

Это простая информационная страница о технологиях веб-разработки. Использованы только HTML и CSS, без JavaScript и сторонних библиотек.

## Как открыть страницу

1. Распакуйте архив целиком.
2. Откройте папку `trpo-pr01-simple` в Visual Studio Code через **File → Open Folder**.
3. Найдите файл `index.html` в левой панели VS Code.
4. Чтобы посмотреть страницу, откройте папку проекта в обычном Проводнике и дважды нажмите на `index.html`. Страница откроется в браузере.
5. Меняйте ширину окна браузера, чтобы проверить мобильную версию.

Устанавливать дополнительные программы для просмотра страницы не нужно.

## Что лежит в папках

- `index.html` — разметка страницы.
- `css/styles.css` — оформление страницы.
- `images/` — картинки, которые отображаются на странице.
- `data/` — копии исходных файлов с данными.
- `dataset/` — исходный набор данных из задания; его файлы не изменены.
- `docs/answers.md` — короткие ответы на контрольные вопросы.

## Как использованы данные

В `dataset/content.csv` находятся шесть записей. Их названия, категории, описания и числовые значения перенесены в карточки и таблицу в `index.html`. В `dataset/navigation.json` описаны четыре пункта навигации; в HTML этим пунктам соответствуют ссылки на разделы страницы. Картинки из `dataset/assets/` скопированы в `images/` и подключены относительными путями.

Для этой учебной работы данные перенесены в HTML вручную — это разрешено заданием. JavaScript не используется.

## Что реализовано

- семантические теги `header`, `nav`, `main`, `section`, `article`, `footer`;
- четыре ссылки навигации по разделам страницы;
- шесть карточек;
- таблица с заголовком, `thead`, `tbody` и шестью строками;
- форма с `label`, текстовым полем, email, числовым полем, `select` и `textarea`;
- атрибуты `required`, `min`, `max`, `minlength`, `maxlength`;
- Flexbox и медиазапрос для мобильного экрана;
- картинки с `alt` и относительными путями.

Форма учебная: браузер проверяет заполнение, но заявка не сохраняется и никуда не отправляется.

## Перед сдачей

1. Откройте страницу и нажмите на все ссылки навигации.
2. Уменьшите ширину окна: карточки и форма должны помещаться на экране.
3. Попробуйте отправить пустую форму и ввести неправильный email.
4. Убедитесь, что картинки показываются.
5. Опубликуйте проект в GitHub и отправьте преподавателю ссылку на репозиторий, а не ссылку на ZIP.
