# Практическая работа № 1
### HTML и базовая CSS-разметка. Семантическая структура страницы

**Учебный портал** — одностраничный информационный сайт о технологиях веб-разработки. Проект демонстрирует семантическую разметку HTML5, оформление на CSS3 и встроенную валидацию HTML-форм.

## Реализованные элементы

- Семантическая структура страницы: `header`, `nav`, `main`, `section`, `article`, `footer`.
- Навигация по разделам с использованием якорных ссылок.
- Шесть информационных карточек и таблица с шестью записями.
- Форма регистрации с полями различных типов и проверкой через HTML5-атрибуты.
- Адаптивное расположение элементов на Flexbox и медиазапрос для небольших экранов.
- SVG-изображения с альтернативными описаниями.

## Используемые технологии

**HTML5**, **CSS3**, **Flexbox**, **Git**.

## Исходные данные

- `dataset/content.csv` — шесть направлений, их категории, описания и показатели.
- `dataset/navigation.json` — названия пунктов меню и идентификаторы разделов.
- `dataset/assets/` — исходные иллюстрации в формате SVG.

Сведения из CSV и JSON использованы при формировании разметки `index.html`; данные представлены непосредственно в HTML без JavaScript. Изображения подключены по относительным путям.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `index.html` | Разметка страницы |
| `css/styles.css` | Стили и адаптивная вёрстка |
| `images/` | Изображения интерфейса |
| `dataset/` | Исходные данные |
| `data/` | Рабочие копии файлов данных |
| `docs/` | Дополнительные материалы |

## Запуск

Проект не требует сборки или установки зависимостей: достаточно открыть `index.html` в современном браузере после получения файлов репозитория.

**Примечание:** форма использует встроенную проверку браузера; сохранение данных на сервере не предусмотрено.
